# skill-creator — Web Harness adaptation

1. Define triggering cases and boundaries from the request. Inspect existing Web Harness discovery, alias precedence, invocation policy and resource conventions before editing.
2. Write concise actionable SKILL.md guidance and references only when useful. Register it through the existing discovery mechanism, retain required licenses and use resource paths returned by list_skills and load_skill.
3. Test positive and negative routing, explicit and implicit policy, loading and resource access. Compare observed task outcomes against representative examples; distinguish returned instructions, declared use and verified artifact quality. Report any unexecuted real-web evaluation.

The fixed upstream original is available as the resource `ANTHROPIC-SKILL.md`; use it and other bundled resources as reference, with this host adaptation taking precedence. Inspect a helper before running it and retain its license.
