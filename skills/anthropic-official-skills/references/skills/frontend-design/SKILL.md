# frontend-design — Web Harness adaptation

1. Inspect the user's brief, existing interface, constraints and project conventions. For Web Harness itself preserve Aura; for an independent artifact choose a direction suited to that task.
2. Define purpose, composition, typography, color and interaction states; implement in the project's existing stack. Avoid imposing a framework or a generic template.
3. Run the application where practical and inspect actual browser screenshots at relevant sizes and interaction states. Iterate on hierarchy, responsiveness and accessibility. Report what was observed and what remains unverified.

The fixed upstream original is available as the resource `ANTHROPIC-SKILL.md`; use it and other bundled resources as reference, with this host adaptation taking precedence. Inspect a helper before running it and retain its license.
