# webapp-testing — Web Harness adaptation

1. Identify the requested behavior, existing test stack, target and test data. Use isolated fixtures and avoid disturbing live sessions.
2. Reuse the project's test runner and available Web Harness browser, screenshot and interaction tools. Observe the actual page before choosing selectors; exercise relevant success and failure states.
3. Inspect screenshots, console and results as appropriate. Distinguish automated checks, visual observations and untested real-web behavior; report reproducible failures and evidence.

The fixed upstream original is available as the resource `ANTHROPIC-SKILL.md`; use it and other bundled resources as reference, with this host adaptation taking precedence. Inspect a helper before running it and retain its license.
