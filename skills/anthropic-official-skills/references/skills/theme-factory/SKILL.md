# theme-factory — Web Harness adaptation

Choose or develop a theme for the task and apply it consistently to typography, color and layout. Web Harness itself retains Aura; independent artifacts follow their own brief. Inspect the rendered result.

The fixed upstream original is available as the resource `ANTHROPIC-SKILL.md`; use it and other bundled resources as reference, with this host adaptation taking precedence. Inspect a helper before running it and retain its license.
