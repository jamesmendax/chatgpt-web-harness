# web-artifacts-builder — Web Harness adaptation

1. Establish the artifact's purpose, behavior, inputs and delivery format. Choose native HTML/CSS/JS or the project's existing framework based on the task; React, Tailwind and bundling are optional.
2. Implement coherent layout, interaction, accessibility and responsive states. For Web Harness itself use Aura; independent artifacts use their own brief.
3. Run and inspect the artifact in a browser, exercise interactions and fix observed problems. Deliver files and describe which browser and visual checks actually ran.

The fixed upstream original is available as the resource `ANTHROPIC-SKILL.md`; use it and other bundled resources as reference, with this host adaptation taking precedence. Inspect a helper before running it and retain its license.
