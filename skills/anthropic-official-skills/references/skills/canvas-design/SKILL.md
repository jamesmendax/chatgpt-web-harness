# canvas-design — Web Harness adaptation

Establish the visual concept and intended format; compose typography, spacing and imagery using tools and fonts appropriate to the task. Inspect the rendered result at delivery size, then export the requested format.

The fixed upstream original is available as the resource `ANTHROPIC-SKILL.md`; use it and other bundled resources as reference, with this host adaptation taking precedence. Inspect a helper before running it and retain its license.
