# Anthropic Skill index

Upstream commit `ca45fc4`; originals and licenses are retained in each child directory. Each `anthropic.<slug>` loads its host adaptation first. Read the original as a reference when useful.

| ID | Trigger |
|---|---|
| `anthropic.academy-guide` | Find or explain explicitly requested Claude Academy or Claude learning materials. |
| `anthropic.algorithmic-art` | Create generative algorithmic art, particle systems or flow fields with code. |
| `anthropic.brand-guidelines` | Apply explicitly requested Anthropic brand identity or brand guidelines. |
| `anthropic.canvas-design` | Create a static visual design, poster, illustration or image artwork. |
| `anthropic.claude-api` | Develop specifically for the Anthropic Claude API, SDK or Anthropic platform. |
| `anthropic.discernment-nudge` | Check assumptions or missing evidence when the user requests critical discernment or a substantive decision needs it. |
| `anthropic.frontend-design` | Design or build a distinctive web frontend, interface, page or application screen. |
| `anthropic.internal-comms` | Draft internal communications, status reports, incident updates, FAQs or handoffs. |
| `anthropic.mcp-builder` | Build or improve an MCP server, its tools and integration. |
| `anthropic.skill-creator` | Create, revise or evaluate an agent Skill and its discovery, guidance, resources or tests. |
| `anthropic.slack-gif-creator` | Create an animated GIF explicitly intended for Slack. |
| `anthropic.theme-factory` | Apply a coherent theme to an explicitly requested artifact or presentation. |
| `anthropic.web-artifacts-builder` | Build an interactive web artifact or prototype with HTML, CSS and JavaScript or an existing framework. |
| `anthropic.webapp-testing` | Test, interact with, debug or capture evidence from a web application in a browser. |

The three provider-specific entries apply only to explicitly relevant Anthropic API development, Claude learning material or Anthropic brand work. Office resources remain excluded.
