# Anthropic Skill collection

Fourteen independent `anthropic.<slug>` entries are listed in `children.json`. Select the relevant child using list_skills or route_skills; its Web Harness adaptation takes precedence over the preserved upstream reference. The upstream collection is https://github.com/anthropics/skills; commit `ca45fc4`, originals, resources and licenses remain in `references/skills`; see `THIRD_PARTY_NOTICES.md`. Restricted Office skills and the unlicensed template are excluded.
